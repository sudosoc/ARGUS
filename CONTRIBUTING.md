# Contributing

SUDOSOC ARGUS is developed by its authors, and **code contributions (pull requests) are not accepted at this time**. This
keeps the copyright in one place so the project can stay under a single licence (AGPL-3.0).

What is welcome:

* **Bug reports** with the version (`argus -version`), what you did, what you expected and what happened.
* **Security reports**: privately, see [SECURITY.md](SECURITY.md).
* **Feedback and ideas**: describe the problem you are trying to solve.

You are free to fork the project under the terms of the [AGPL-3.0](LICENSE). A fork must use a different name and different
artwork (see [NOTICE.md](NOTICE.md), *Trademarks and branding*).

If you want to build on the code, [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) and [docs/WRITING-A-MODULE.md](docs/WRITING-A-MODULE.md)
explain how it is organised.
